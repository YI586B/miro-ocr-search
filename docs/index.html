Miro-ocr-search

Find any word in a folder full of images, see it highlighted on the image, and send what you found to a file or a Miro board.

Download for Mac Installation help

Free · Version 1.2 · macOS 13 Ventura or later · Macs with Apple chips (M1 or newer)

What it is

Images hold a lot of useful text, but your Mac can't search inside them the way it searches a document. Miro-ocr-search fixes that.

It's a search tool, not an image editor: it finds the words in your images and shows you where they are. Images it saves or sends to Miro carry a Miro watermark, because the app uses Miro's libraries.

📂

Point it at a folder

Pick any folder of images. The app reads the text in every image, including images in folders inside it.

🔎

Search like a document

Type a word or phrase and you see every image that contains it straight away.

🖍️

See it on the image

Matches are marked on the picture itself. The app can also rewrite them in a font that matches the original.

📤

Share the results

Save what you found as a spreadsheet, a document or finished images, or put it straight onto a Miro board.

Who it's for

Anyone who collects images and has to find things in them later: researchers going through app screens, designers pulling examples together, support teams looking for a particular error message, or anyone preparing a Miro workshop from a pile of captures.

Your images stay on your Mac

The text is read by software built into macOS. You don't need an account or an internet connection, and your images are never uploaded anywhere. The only exception is when you choose to send results to Miro.

How to install

Installing takes about two minutes. The first time you open the app there's one extra step, explained below.

  1. Download the app Click Download for Mac. You'll get a file called Miro-ocr-search-1.2.dmg in your Downloads folder.
  2. Open the download Double-click the file. A window opens showing the app and your Applications folder.
  3. Drag it into Applications Drag the Miro-ocr-search icon onto the Applications folder in that window.
  4. Allow it to open (first time only) macOS will block the first launch. This is expected. Follow the steps in the box below.

“Cannot be opened because the developer cannot be verified” or “is damaged”

The download isn't broken. Apple charges developers a yearly fee to register their apps, and this free app isn't registered, so macOS warns you. You only need to allow it once.

Try this first: open your Applications folder, right-click (or Control-click) Miro-ocr-search, choose Open, then click Open again in the warning.

If there's no Open button: open the Terminal app (search for it with ⌘ Space), paste this line, press Return, then open the app as usual:

xattr -dr com.apple.quarantine /Applications/Miro-ocr-search.app

How to use it

From opening the app to your first result.

  1. Choose a folder Click Choose folder… at the top of the window and pick the folder holding your images.
  2. Wait while it reads The app reads the text in every image. A couple of dozen images take about ten seconds. This happens once each time you open a folder.
  3. Type what you're looking for Results appear as you type. Choose Phrase to find the words together in that order, or Any word to find images that contain all the words anywhere.
  4. Look closer Double-click a result to open it full size, with every match marked. Use ⌘[ and ⌘] to move between results, and the search box at the top to look for something else on the image.
  5. Export what you need Tick the results you want to keep and choose Export to file or Export to Miro.

Features

What the app can do.

Instant search

Once a folder has been read, results show up as fast as you can type.

Two ways to highlight

Boxes puts a coloured box over each match. Text rewrites the match on the image, which is useful for mock-ups and presentations. Use either one or both. Both are on to start with.

Matches the original look

In Text mode the app works out the font, size, colours and spacing from the image, so the new text blends in.

Fine-tune any image

The Style button opens a panel beside the image where you can change the font, size, colours or spacing yourself. Changes apply only to that image.

Export to files

Save results as a spreadsheet (CSV), a readable document (Markdown), or full-quality images with the highlighting built in.

Export to Miro

Send the chosen images to a new or existing Miro board, each with a sticky note of its text.

English and Dutch

Text in English and Dutch is recognised. Common formats work: PNG, JPEG, HEIC, TIFF, GIF, BMP and WebP.

Private by design

Everything happens on your Mac. Your original images are never changed. Exports are always saved as new files.

Report a bug or ask for a feature

Found something that doesn't work, or have an idea? We'd like to hear about it.

  1. Open the issue page Go to Issues on GitHub and check whether someone has already reported it. If they have, add your details there.
  2. Create a new issue Click New issue. You'll need a free GitHub account.
  3. Tell us what happened Include:
    • what you were trying to do
    • what you expected, and what happened instead
    • your macOS version and Mac model (Apple menu ▸ About This Mac)
    • an image of the problem, if you can

Take care with images. Issues are public. Don't attach images that show private or confidential information.

Contributing code, step by step

  1. Start with an issue Before starting on something big, open an issue and say what you'd like to change, so nobody duplicates work.
  2. Fork and build Fork the repository, then build it on your Mac. You'll need Apple's free command line tools (xcode-select --install): 
    git clone https://github.com/<your-name>/miro-ocr-search.git
cd miro-ocr-search
./build-app.sh
open "Miro-ocr-search.app"
  3. Make your change on a branch Keep each change focused on one thing. If you change how the app behaves, update the full guide as well.
  4. Open a pull request Push your branch and open a pull request that says what you changed and how you tested it.

Questions & answers

The questions people ask most.

Is it free?

Yes. There's no price, subscription or account.

Is this an official Miro product?

No. It's an independent project that can send results to Miro. It isn't made, endorsed or supported by Miro.

Why does macOS say the app is “damaged” or from an “unverified developer”?

Apple charges developers a yearly fee to register their apps, and this free app isn't registered. The download is fine. Follow the first-launch steps once and the warning won't come back.

Are my images uploaded anywhere?

No. Text is read on your Mac by software built into macOS. Nothing leaves your computer unless you choose Export to Miro, and then only the images you ticked are sent, to your own board.

Will it change or delete my original images?

No. The app only reads your images. Anything you export or save is written as a new file.

Does it work on Windows, or on an older Intel Mac?

Not on Windows, because it relies on text recognition built into macOS. The download runs on Macs with Apple chips. On an Intel Mac, someone comfortable with the Terminal can build it from the source code instead (see Contributing code).

Why does it take a few seconds every time I open a folder?

The app reads your images fresh each time rather than keeping a separate copy of their text, so results always match what's in the folder right now. Reading is the slow part. Searching afterwards is instant. If you add images while the app is open, use Reload in the folder menu.

It isn't finding a word I can see in the image. Why?

Very small, blurry, stylised or handwritten text can be hard to read. Only English and Dutch are recognised. Try a shorter part of the word, or switch between Phrase and Any word.

How do I connect my Miro board?

When you choose Export to Miro, a window asks for a Miro access token. Its Where do I get one? link takes you to the page in your Miro settings where you create one. Give it permission to read and write boards. Then choose to create a new board or add to an existing one. The app keeps the token in your Mac's Keychain, the same secure place your passwords are stored, so you only enter it once. Miro export is new, so please report anything that goes wrong.

What's the small badge in the corner of exported images?

A Miro watermark. The app uses Miro's libraries, so the images it outputs carry it. It's added to images that have highlighting turned on; if you turn the highlighting off, you get the plain image without it.

I changed the style of an image and now it's gone. What happened?

Style settings are remembered by where the file is. If you move or rename an image, the app treats it as a new image and starts from the default look.

How do I remove the app?

Drag Miro-ocr-search from your Applications folder to the Bin. Your images aren't affected.
